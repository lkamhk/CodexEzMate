# 自訂自動命名規則（1.22.0）

在「設定 → 基本設定 → 自動命名規則」可啟用命名、增減及排列命名段，並指定共用分隔符。
全部使用本機規則，**不提供 AI 摘要、不額外呼叫模型、不消耗 token**。

每段可選：Project 名（會話工作目錄最後一層名稱）、第一條 prompt、最新 prompt、固定文字或 Session ID。
Project 名並非 Codex 側邊欄自訂的項目顯示名稱。
可建立 1–8 段，每段字數上限為 1–100，所有段及分隔符合計上限為 240 字。
字數按可見字元計算，避免切斷 emoji；超出時的 `…` 亦計入上限。
分隔符保留空格，例如 `|` 與 ` | ` 不同；缺少內容的段會略過，不留下多餘分隔符。

例如選擇「Project 名 20 字 → 第一條 prompt 15 字 → 最新 prompt 30 字」，分隔符輸入 `|`：

```text
myProject|建立會話瀏覽器|加入自訂命名規則
```

↑／↓ 可以調整段落次序。下方預覽使用示例資料，不會改動任何會話。
按基本設定的「儲存」後才套用規則；「取消」不儲存規則修改。
已存在的舊設定會保留舊命名行為，直到修改規則並儲存。改規則不會批量重命名歷史會話，只影響之後完成回覆的會話。
啟用／停用通知區的自動命名開關不會清除規則或排除名單。

## 排除名單

按「管理排除名單…」可搜尋名稱或 Session ID，左邊選取會話後按「加入所選 →」，或直接輸入有效 UUID 按「按 ID 加入」。
右邊選取一個或多個項目後按「← 移除排除」即可恢復之後的自動命名。
此操作只管理排除設定，不會刪除會話；找不到本機會話的 ID 仍可保留或移除。
排除變更會**獨立即時儲存**，不受基本設定視窗的取消按鈕影響。
會話瀏覽器既有的排除／恢復選單與此視窗共用同一份名單。

設定存於 EzMate 資料根目錄的 `settings/session-auto-naming.json`。
設定只保存規則、排除 ID 及未確認操作的雜湊，不保存 prompt 內容。
