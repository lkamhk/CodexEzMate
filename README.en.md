## Four core features

| | What you can do |
| --- | --- |
| **🔔 Reset release alerts** | Follow reset previews and release announcements, with notifications for new or revised notices. Separately, receive a notification when your account’s available reset count increases. |
| **🗂️ Batch session management** | Select multiple sessions to back up, move to Trash, restore, or send trashed files to the Windows Recycle Bin. Includes search, user/AI conversation previews and optional automatic naming. |
| **▶️ Automatic Goal recovery** | Continue selected Goals in their original Codex Desktop conversations after usage quota becomes available again. **The maintainer has successfully tested recovery.** |
| **💧 Standalone usage monitoring and reset control** | View 5-hour and weekly quotas, available resets and expiry times, and confirm reset use in EzMate, **without opening the Codex Desktop App**. |
